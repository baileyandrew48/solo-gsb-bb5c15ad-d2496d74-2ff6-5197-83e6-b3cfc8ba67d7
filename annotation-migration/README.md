# 文稿批注迁移工具

供校对人员使用的单机网页工具：在**旧版文稿**上框选文字写批注，粘贴**新版文稿**后，系统根据批注的「选中文本 + 前后文」在新版中自动重新定位；重复片段会比较上下文，仍有多个合理位置或原文已删除时标为**待处理**，绝不静默挂到错误段落。新稿与定位结果**左右并排显示**，校对员可人工选定位置后保存。

- 后端：Node.js + Express（仅依赖 express）
- 前端：原生 HTML / CSS / JavaScript，无构建步骤
- 存储：单机 JSON 文件（`data/db.json`），随容器卷持久化
- 无外部数据库、无账号体系，适合内网/个人机器运行

## 一条命令启动

需要本机已安装 Docker（含 Docker Compose 插件）。在本目录执行：

```bash
docker compose up -d --build
```

首次执行会自动：安装 Node 依赖 → 构建镜像 → 创建 `data/` 数据目录 → 启动服务。

启动后用浏览器访问：

> **http://localhost:3000**

端口为 **3000**（宿主机与容器均为 3000，可在 `docker-compose.yml` 的 `ports` 中修改左侧端口，如 `"8080:3000"`）。

常用命令：

```bash
docker compose logs -f      # 查看日志
docker compose down         # 停止并移除容器（data/ 中的数据保留）
```

## 不用 Docker 时的本地启动（需 Node.js ≥ 18）

```bash
npm install
npm start
# 同样访问 http://localhost:3000
```

数据保存在项目下的 `data/db.json`，备份整个 `data/` 目录即可。

## 使用流程

1. **新建项目**：打开首页，输入项目名称（如「第三版社论校对」）并创建。
2. **粘贴旧稿**：在「1. 旧稿 · 框选批注」页粘贴旧版文稿全文并载入。
3. **框选批注**：在旧稿正文中按住鼠标选中文字，在弹出框中填写批注内容与校对人，保存。可添加任意多条。
4. **粘贴新稿**：切换到「2. 新稿 · 定位与核对」页，粘贴新版文稿全文，点击「粘贴并执行迁移定位」。
5. **并排核对**：
   - 左侧新稿高亮显示每条批注的定位位置，右侧列出定位结果卡片（点击卡片/高亮可互相定位、滚动）。
   - 🟢 **已定位**：唯一匹配或上下文明显区分；模糊（空白差异）命中会特别标注及相似度。
   - 🔵 **人工确认**：由校对员手动框选确认的位置。
   - 🔴 **待处理**：原文已删除 / 存在多个合理位置。歧义时卡片会列出全部候选片段及各自的上下文相似度，可：
     - 直接点击某条**候选**采纳；
     - 点「在新稿框选位置」，在左侧正文中重新框选正确文字并「确认位置」；
     - 确认确属删除/无法处理，可点「已核对，保持待处理」。
6. **保存**：所有操作均即时写入服务器文件，顶栏显示「已保存 HH:MM:SS」。「全部重新定位」可强制重算（会清除人工确认，执行前需再次确认）。

> 更换旧稿会清空该项目的全部批注（坐标失效），操作前有确认提示；更换新稿后批注会基于新旧稿重新迁移，人工确认过的位置默认保留。

## 定位算法说明（lib/relocate.js）

1. 在新稿中查找批注原文的全部出现位置；找不到时退化为「忽略空白差异」的模糊匹配（仅允许空白增减，不改字）。
2. 存在多个出现位置时，用旧稿中该选区前后各 20 字的上下文，与每个候选位置的前后文做字符二元组（bigram）Dice 相似度比较。
3. 判定规则：
   - 唯一出现 → 自动定位（模糊匹配质量过低则仍转待处理）；
   - 多处出现且最优候选相似度足够（≥ 0.40）且明显领先次优（差距 ≥ 0.12）→ 自动定位；
   - 否则标记为 **待处理：多处可能**，列出候选交人工裁决；
   - 完全找不到 → **待处理：原文已删除**。

阈值均可在 `lib/relocate.js` 顶部调整。

## 目录结构

```
annotation-migration/
├── Dockerfile
├── docker-compose.yml
├── package.json
├── server.js            # Express 服务与 API
├── lib/
│   ├── relocate.js      # 批注迁移定位引擎
│   └── storage.js       # JSON 文件持久化
├── public/              # 原生前端
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── data/                # 运行时生成，存放 db.json（已挂载为卷）
```

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/projects` | 项目列表 |
| POST | `/api/projects` | 新建项目 |
| GET / DELETE | `/api/projects/:id` | 读取 / 删除项目 |
| PATCH | `/api/projects/:id` | 更新标题 / 旧稿 / 新稿 |
| POST | `/api/projects/:id/annotations` | 在旧稿选区上新增批注 |
| PATCH / DELETE | `/api/projects/:id/annotations/:aid` | 修改 / 删除批注 |
| POST | `/api/projects/:id/migrate` | 执行（或强制重算）迁移定位 |
| POST | `/api/projects/:id/annotations/:aid/manual-locate` | 人工选定新稿位置 |
| POST | `/api/projects/:id/annotations/:aid/mark-pending` | 标记已核对、保持待处理 |
